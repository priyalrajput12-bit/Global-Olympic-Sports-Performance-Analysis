# Global Olympic Sports Performance Analysis

## 1. Introduction
The Olympic Games bring together athletes from different countries to compete in various sports. This project analyzes Olympic athlete data to understand participation and medal performance.

## 2. Project Objective
The objective is to analyze Olympic data, explore medal distribution, identify countries with the highest medal records, and study athlete participation over the years.

## 3. Data Analysis
The project uses data visualization to explore:
- Gold, Silver, and Bronze medal distribution.
- Top 10 countries by medal records.
- Athlete participation across Olympic years.

## 4. Key Insights
- Medal distribution charts help compare different medal types.
- Country-wise analysis highlights countries with the most medal records.
- Year-wise participation charts show changes in athlete participation over time.

## 5. Conclusion
The interactive dashboard makes Olympic data easier to explore and understand. It helps users identify patterns in medal records and athlete participation.

## 6. Dashboard
The interactive dashboard is deployed using Streamlit Community Cloud.
